# Decision Log

Use this file to record important project decisions and the reasoning behind them.

## Template

### Date

YYYY-MM-DD

### Decision

Describe the decision.

### Context

Explain the background, constraints, or problem that motivated the decision.

### Reasoning

Explain why this option was chosen over alternatives.

### Impact

Mention the expected consequences for the project, team, or implementation.

### Owner

Name or role responsible.

---

## Example entry

### 2026-08-30

### Decision

Use GitHub Issues and pull requests as the default project management flow.

### Context

The team needs a clear process for tracking tasks, assigning work, and reviewing changes.

### Reasoning

GitHub provides a simple workflow that supports issue tracking, pull requests, and version history without requiring extra tooling.

### Impact

The team will work with feature branches, review-based merging, and structured documentation.

### Owner

Team
